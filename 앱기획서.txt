========================================
          앱 기획서 (간단 요약)
========================================

1. 주제 (게임의 통계, 정보 등을 알려주는 앱)
   - 앱 이름:
   - 한 줄 소개: 게임의 통계나 정보 등을 알려주는 앱
   - 핵심 아이디어: 현재 가장 많이 사용하는 스팀 게임같은 것을
       나타낼 수 있음


2. 목적
   - 왜 만드는가: 위와 같은 정보를 궁금해 하는 사람들을 위해서
   - 누구를 위한가 (대상 사용자): 위와 같은 정보를 궁금해 하는 사람들
   - 사용자가 얻는 가치: 다양한 게임들의 정보를 얻음으로서 그 게임들에
      흥미나 관심이 생기고 찾아서 해볼 수 있음


3. 문제와 해결
   - 현재 불편한 점: 게임의 순위나 정보를 하나하나식 다 찾아봐야함
   - 이 앱이 해결하는 방법: 한 앱에 다양한 게임들의 정보를 나타냄으로서
      간단하고 편리하게 정보를 찾아 볼 수 있음


4. 주요 기능
   [필수]
   - 기능 1: 인기 게임 순위 (스팀 현재 동접 순으로 지금 많이 하는 게임)
   - 기능 2: 게임 검색 (이름 입력해서 찾기)
   - 기능 3: 게임 상세 정보 (설명, 가격, 장르, 리뷰 점수, 현재 플레이 인원)
   - 기능 4: 새로고침 (최신 순위/동접 다시 불러오기)

   [선택]
   - 기능 5: 롤 전적 검색 (라이엇 ID로 티어, 승률, 최근 경기)
   - 기능 6: 즐겨찾기 (관심 게임 저장 후 바로 보기)
   - 기능 7: 트위치 "지금 많이 보는 게임" (방송 시청자 수)


5. 화면 구성
   - 화면 1: 홈 / 인기 순위 (스팀 지금 많이 하는 게임 목록)
   - 화면 2: 검색 (게임 이름 검색, 결과 목록)
   - 화면 3: 게임 상세 (정보, 가격, 동접, 리뷰)
   - 화면 4: (선택) 롤 전적 검색 / 결과
   - 화면 5: (선택) 즐겨찾기 목록


6. 사용 순서 (시나리오)
   1) 앱을 연다
   2) 홈에서 지금 스팀에서 많이 하는 게임 순위를 본다
   3) 궁금한 게임을 누르거나, 검색으로 찾는다
   4) 상세 화면에서 정보·가격·동접·리뷰를 본다
   5) (선택) 관심 게임을 즐겨찾기에 넣거나, 롤 닉네임으로 전적을 검색한다


7. 데이터 / 저장
   - 저장할 정보: 즐겨찾기한 게임, (선택) 최근에 검색한 롤 닉네임
   - 저장 방식: 순위·게임 정보는 백엔드가 스팀/라이엇 API에서 가져와 앱에 전달
                 즐겨찾기만 폰에 로컬 저장 (회원 DB는 없어도 됨)


8. 차별점
   - 비슷한 앱과 다른 점:
     이미 SteamDB, 스팀 스토어, op.gg처럼 비슷한 웹이 있음
     다만 대부분 영어 웹이고, 순위 / 정보 / 전적을 사이트마다 따로 봐야 함
     이 앱은 한국어 모바일에서 인기 순위 + 게임 정보(+ 롤 전적)를
     한곳에서 간단히 보게 하는 것이 차별점


9. 제약 / 참고
   - 기술 제약: 스팀 동접·게임 정보, 롤 공개 전적은 공식 API로 가능
                 구글 플레이/웹 실제 방문자 수, 정확한 매출은 가져올 수 없음
                 개발용 API 키는 만료·요청 횟수 제한이 있음
   - 참고 앱 / 아이디어: 스팀 스토어(모스트 플레이드), SteamDB, SteamCharts,
                         op.gg, RAWG, 트위치


10. 개발 언어
    [선택] React Native 로 개발 가능함. (이 앱은 화면+API 호출이라 적합)
    - 앱(화면): JavaScript 또는 TypeScript (React Native)
    - 권장: Expo 로 시작 (안드로이드·아이폰 같이 확인하기 쉬움)
    - 백엔드: Python (Flask 또는 FastAPI)
              또는 JavaScript (Node.js) — 프론트와 언어를 맞출 때
    - 데이터 형식: JSON
    - 화면 이동: React Navigation
    - 서버 통신: fetch 또는 axios
    - 즐겨찾기: AsyncStorage (폰 로컬 저장)

    [다른 선택]
    - 안드로이드만: Kotlin
    - 웹: HTML, CSS, JavaScript
    - 다른 크로스플랫폼: Dart (Flutter)


11. 백엔드
    - 꼭 필요한가:
      필수 기능(스팀 순위·검색·상세)만 하면 앱에서 스팀 API를
      바로 호출해도 됨. 다만 API 키 보호, 요청 횟수 제한 때문에
      백엔드를 두는 것을 권장.
      롤 전적(선택 기능 5)을 넣으면 백엔드가 필요함.
      (라이엇 API 키를 앱에 넣으면 키가 노출됨)

    - 백엔드가 하는 일:
      1) 앱 요청을 받아서 스팀 API에 대신 물어봄 (순위, 검색, 상세, 동접)
      2) (선택) 라이엇 API에 대신 물어봄 (롤 전적)
      3) (선택) 트위치 API에 대신 물어봄
      4) 받은 JSON을 정리해서 앱에 돌려줌
      5) (가능하면) 잠깐 저장해 두고 같은 요청을 줄임 (캐시)

    - 백엔드가 안 하는 일:
      로그인/회원 기능은 필수가 아님
      즐겨찾기는 폰에만 저장하면 됨 (DB 서버 불필요)

    - 외부에서 가져오는 데이터:
      스팀 Web API  → 인기 순위, 게임 정보, 동접, 리뷰
      라이엇 API    → 롤 티어, 승률, 최근 경기 (선택)
      트위치 API    → 지금 많이 보는 게임 (선택)

    - 흐름:
      React Native 앱 → 내 백엔드 → 스팀/라이엇 → 내 백엔드 → 앱 화면에 표시


12. 개발 전 준비물
    [계정 / 키]  — 키는 절대 앱이나 깃허브에 올리지 말 것
    - 스팀 계정 + Steam Web API 키  (필수 기능용)
      https://steamcommunity.com/dev/apikey
    - 라이엇 개발자 계정 + API 키   (롤 전적 넣을 때만)
      https://developer.riotgames.com/
      ※ 개발용 키는 보통 24시간마다 갱신
    - 트위치 개발자 계정            (선택 기능 7을 넣을 때만)
    - Expo 계정                     (있으면 편함, 필수는 아님)

    [컴퓨터에 설치]
    - Node.js (LTS)
    - 코드 편집기 (VS Code 또는 Cursor)
    - Git
    - Expo Go 앱 (테스트할 폰에 설치) 또는 안드로이드 에뮬레이터
    - 백엔드를 Python으로 하면: Python 3
    - 백엔드를 Node로 하면: Node.js만 있으면 됨

    [알아야 하는 것]  (완벽하지 않아도 시작 가능)
    - JavaScript 기본 (변수, 함수, 배열, 객체)
    - React 기본 (컴포넌트, state)
    - JSON, HTTP 요청 (fetch)이 뭔지
    - API = 다른 서버에 정보를 물어보는 것

    [기획에서 미리 정해 둘 것]
    - 앱 이름
    - 필수 기능만 할지, 롤 전적까지 할지
    - 화면 대략 스케치 (홈 / 검색 / 상세)
    - 백엔드를 Python으로 할지 Node.js로 할지
